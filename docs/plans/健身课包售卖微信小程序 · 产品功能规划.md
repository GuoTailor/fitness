# 健身课包售卖微信小程序 · 产品功能规划

> 日期：2026-10-23
> 状态：已与需求方逐段确认

## 1. 产品定位

面向**自营健身工作室**的「卖课包 + 约教练」微信小程序：

- 核心商品：线下课程课包（私教次卡、团课卡、体验课）
- 线上视频仅用于课程展示与辅助种草
- 训练跟踪的呈现风格参考 Keep
- 用户可评价留言，形成口碑闭环

**业务闭环**：课程介绍种草 → 购买课包（微信支付）→ 预约教练 / 报名团课 → 线下核销上课 → 课时消耗跟踪 → 课后评价 → 复购/升包

### 经营模式决策

先自营（本工作室教练团队），数据模型预留平台化扩展（教练、课包等核心实体带归属字段），未来可开放外部教练入驻。

## 3. 用户端功能模块

### 3.1 首页

- Banner 运营位（后台可配）
- 课包推荐位（新品 / 热销 / 高评分）
- 教练频道入口
- 本周团课日历入口
- 搜索（课包 / 教练）

### 3.2 课程介绍（课包商城）

- 分类：私教 1v1 / 团课 / 体验课；按训练目标（减脂 / 增肌 / 塑形 / 康复…）
- 课包详情页：介绍视频、课程大纲（教什么）、课时规格（10 次 / 20 次）、有效期、适合人群、难度、教练信息、价格、用户评价区
- 购买：选规格 → 微信支付 → 课时入账 → 引导立即预约

### 3.3 教练介绍

- 教练列表：按擅长领域、评分筛选
- 教练主页：头像、资质认证标识（后台审核后展示）、从业年限、自我介绍（可含视频）、学员评价聚合、在售课包、可约时段入口

### 3.4 预约上课

**私教预约**：选教练 → 空闲时段日历（30 分钟/格）→ 选课包扣次 → 提交预约 → 教练确认（订阅消息双向通知）→ 到店核销

- 取消规则：开课前 X 小时内取消扣 1 课时，此前免费取消（后台可配置）

**团课报名**：教练发布团课（时间 / 地点 / 项目 / 容量 / 适用卡种）→ 课表日历浏览 → 报名占名额并扣次 → 满员候补（P1）→ 到课核销

- 退出规则：开课前 X 小时可退出并返还课时（后台可配置）

### 3.5 课程跟踪

- **课包层**：总课时 / 已消耗 / 剩余 / 有效期；快用完、快到期订阅消息提醒
- **训练层**：每次上课自动生成训练记录（日期、项目、教练、时长）；日历打卡视图
- **数据层**：周 / 月统计（上课频次、课时消耗）、可选体重曲线（Keep 风格）

### 3.6 评价留言与课程问答

**课后评价**：

- 核销完成次日推送评价邀请（订阅消息）
- 双维度评价：课包评价（内容效果）+ 教练评价（专业度 / 服务）
- 星级 + 文字 + 图片；完成至少 1 次核销才可评价（防刷单）
- 后台审核后展示；教练可回复评价

**课程问答区（P1）**：

- 位置：课包详情页评价区旁（Tab 切换），公开展示历史问答，解决购前疑虑（类似电商「问大家」）
- 提问：登录即可提问（不限已购——购前疑问正是问答区的核心价值）；提问可选匿名展示
- 回复：教练与已购学员可回复；教练回复带认证标识，排序优先展示
- 通知：新提问 → 订阅消息提醒该课包教练；教练回复 → 订阅消息通知提问者
- 审核：先发后审（不打断提问体验），后台可删违规内容（含导流联系方式等）
- 置顶：后台 / 教练可将优质问答置顶，沉淀为常见问题（FAQ）

### 3.7 订单与资产

- 订单列表、申请退款
- 优惠券：领券中心、我的券包（P1，见第 7 章营销工具）

### 3.8 我的

- 微信登录（wx.login + 手机号快速授权）
- 个人资料、训练数据总览
- 客服（微信客服）

### 3.9 退款规则（后台可配置）

- 未开卡：N 天内全额退
- 已开卡：按已消耗课时的单次原价折算，退还余额

## 4. 教练工作台（同小程序双角色）

| ---- | --------------------------------- |
| 主页管理 | 资料、资质证书、自我介绍维护                    |
| 私教日历 | 每周可约时段模板、确认/拒绝预约、当日课表             |
| 团课管理 | 发布/取消团课、报名名单、扫码核销（学员出示二维码，教练扫码扣次） |

| 留言答疑 | 回复课包详情页学员提问（新提问订阅消息提醒，可置顶常见问答） |

## 5. Web 管理后台

- **课包管理**：上架/下架、分类、规格与价格、介绍视频素材
- **教练管理**：资料维护、资质审核、排班权限
- **订单管理**：流水、退款处理、课时对账
- **预约管理**：全馆课表视图、前台代客预约/核销
- **评价/留言管理**：评价审核、精选、删除违规；问答区内容审核与置顶管理
- **学员管理**：档案、剩余课时、手动调整课时（赠课/补课）
- **运营配置**：Banner、取消/退款规则、订阅消息模板
- **数据看板**：GMV、课消率、复购率、教练排行

## 6. 技术方案

- 前端：微信小程序原生（或 uni-app 跨端）
- 后端：Go/ Java + MySQL
- **视频：自建服务器存储**，nginx 静态目录直接提供 https 播放地址（仅课程介绍类短视频，流量规模可控；不引入对象存储与 VOD，后续有需要再升级）
- 支付：微信支付（线下服务类目，不受 iOS 虚拟支付限制）
- 消息：微信订阅消息（预约确认、评价邀请、课时/有效期预警）
- 关键机制：
  - 预约时段防冲突（并发锁 / 乐观锁）
  - 扣次幂等（防重复扣次、团课防超卖）
  - 平台化预留：教练、课包、订单等核心实体带归属字段
- 合规：收集手机号、体重等健康数据需配置隐私协议与用户授权

## 7. 营销工具体系

按「底座 → 工具」分层。核心商业逻辑：**课消率优先**——课时消耗越快，续费越快，促活类营销价值最高。

### 7.1 营销底座：优惠券系统（P1，最先做）

所有价格类营销的地基：

- **券类型**：满减券 / 折扣券 / 指定课包券 / 赠课券（赠 1 课时，行业最常用）
- **发放渠道**：新人自动发放、领券中心入口、后台定向发、评价/打卡奖励
- **规则引擎**：有效期、适用课包范围、使用门槛；与营销价默认不叠加、取最低价
- **退款联动**：用券订单退款后，券在有效期内自动返还
- **核销对账**：后台查看券的领取率 / 使用率

### 7.2 新人价 + 新人礼包（P1，实现成本低）

- 课包 SKU 打「新人价」标签（限定人群的价格），每人限购 1 次（手机号判重）
- 新人礼包：注册即自动发券组合（体验课券 + 满减券）
- 体验课包作引流品，详情页强引导「预约第一节」

### 7.3 限时活动价（P1）

- 后台配置限时价 + 时间段，前端倒计时展示
- 配合首页 Banner 做节奏运营（开业 / 节日 / 周年）

### 7.4 老带新裂变（P2，合规敏感）

- 学员生成专属海报/分享码，新客下单后**双方各得奖励**
- 奖励优先用赠课时/返券，规避资金结算合规问题
- 若做现金佣金：**只能一级分销**（微信严禁多级，违规封小程序），需签约主体与结算记录
- 邀请关系绑定：落地页绑定，30 天内下单有效

### 7.5 拼团（P2）

- 团课卡天然适合拼团（拉朋友一起练）
- 2~3 人成团，团长价优惠，分享卡片直接开团

### 7.6 促活复购

- **续费提醒券（P1）**：绑定「课时不足预警」订阅消息，触发时自动发续费优惠券，成本低价值高
- **打卡挑战（P2）**：月度上课 N 次返券 / 赠课时
- **会员储值（P2 前需合规评估）**：充值送——预付资金监管趋严，部分地区单用途预付卡需备案；做之前先查当地政策，或放弃
