## 批次① 营销收尾

### 限时活动价

- `package_sku` 加 `promo_price BIGINT NULL / promo_start DATETIME NULL / promo_end DATETIME NULL`；`orders` 加 `promo_used TINYINT DEFAULT 0`。
- 生效判定 `promoDiscountOf(sku, now)`：`promo_start ≤ now < promo_end` 且 `1 ≤ promo_price < price`，优惠额 = `price - promo_price`。
- **三方比价（服务端下单终判）**：`promoOff / newcomerOff / couponOff` 只应用单一最大优惠；**同额优先级 promo > newcomer > coupon**（活动价不限次，同额时保住新人一次性资格与券）。与既有「不叠加取最低」语义一致。
- 详情接口 skuView 在活动期内输出 `promoPrice/promoEnd`；前端角标+倒计时、`computePay` 参与取最低、订单列表「活动价」标签。
- 后台 SKU 行：活动价金额 + 起止时间；校验 0（关闭）或 1分 ≤ 价 < 售价 且 end > start。

### 赠课券（券类型 gift）

- `CouponTypeGift = "gift"`，模板 Amount = 赠送课时数（1~10），Threshold 强制 0；`CouponBenefit` 返回 0（不降价）。
- 下单：gift 券**不降价、可与活动价/新人价同时生效**（价格优惠照常计算，券仅绑单赠课时）：预读校验范围+可用，事务内 `ApplyCouponForOrder` gift 分支只做 usable→used 绑定、返回 0；订单记 `gift_sessions`。
- 入账 `creditSessions`：`total_sessions = SkuSessions + gift_sessions`，`member_package.gift_sessions` 落列；赠课独立流水 `TxnTypeGift`、幂等键 `gift:{orderNo}`。
- 退款：券返还复用 `returnCouponOnRefund`；**已开卡折算可退课时 = max(0, total - gift - used) × unit_price**（赠课永不退钱）；未开卡全额退 = 实付金额，不受赠课影响。

### 评价奖励发券 / 续费提醒券

- 配置键：`marketing.review_reward_template`、`marketing.renewal_reminder_template`（券模板 ID，空=关闭），进后台保存白名单与 Settings 页。
- 评价奖励：`ReviewService.Audit` approve 分支与 `Submit` 自动通过分支 → `Claim`（失配/超限仅记日志）；重复发放由模板 per_user_limit 天然控制。
- 续费提醒券：`task.Runner` 装配 `CouponService`；`MemberWarnings` 课时不足分支对每个预警课包尝试 `Claim`——首次预警发券、后续超限静默跳过。

## 批次② 预约体验

### 教练请假

- 表 `coach_leave(coach_id, leave_date, start_minute, end_minute, reason)`；`SlotsOfDate` 排除重叠格；`Create` 事务内拒绝与请假重叠的预约。
- 教练端 `GET/POST/DELETE /api/v1/coach/leaves`（本人名下）；coach-admin 时段页加「请假管理」。存量预约不自动取消（教练线下处理）。

### 团课候补（自动递补）

- 表 `group_waitlist(group_class_id, user_id, member_package_id, status waiting|promoted|failed|canceled)`，UNIQUE(class, user)。
- `Enroll` 事务体重构为 `enrollInTx(tx, gc, userID, mpID)`，报名与递补共用（复用行 + enroll_seq + 条件占位 + 扣次幂等键 `group_deduct:{id}:{seq}`）。
- `Waitlist`：满员（enrolling 且满 / fulfilled）时受理，校验课包可用但不扣次；`CancelWaitlist` 可退出。
- `Quit` 释放名额后**同事务** `promoteOneWaiting`：FIFO 取 waiting，课包失效/课时不足 → 标 failed 继续下一位；占位失败（又满）即停；成功标 promoted + 事务外通知（场景 `waitlist_promoted`）。教练取消整课不递补。
- 课表接口按当前用户输出 `waitlisted` 标记；小程序满员卡「候补报名」（选课包）/「候补中」+取消。

### 教练列表筛选

- `CoachService.List` 加 `minRating`（rating_avg ≥）与 `specialty`（LIKE）；小程序教练列表评分 chips（全部/4.0+/4.5+）。

## 批次③ 跟踪强化

### 教练课后反馈

- 表 `class_feedback(verification_id UNIQUE, coach_id, user_id, content, created_at, updated_at)`。
- `POST /api/v1/coach/feedback {verificationId, content}`：校验核销单归属该教练；uk 允许修订；写后通知学员（场景 `feedback_new`）。
- 学员 `GET /api/v1/feedback/mine`；预约详情（completed）按 verification 关联展示反馈；coach-admin 新「学员反馈」页（近期核销列表+填写）。

### 体重记录

- 表 `body_metric(user_id, record_date, weight_g 克整数)`，UNIQUE(user, record_date) 同日 upsert。
- `POST /api/v1/body-metrics {date, weightG}`（100g 粒度）、`GET ?limit=` 升序。训练跟踪 tab 体重卡：当前值+录入+纯 CSS 折线近 30 次。体重属健康数据，隐私协议已覆盖。

### 训练周报

- `GET /api/v1/training/report?date=`（周一起算）：本周/上周上课数、总分钟、活跃天数、私教/团课占比、教练课时 Top、周内体重首末差。
- 新页 `pages/training/report`：周切换 ‹› + 对比卡 + 教练榜 + 体重线。

## 批次④ 课程问答区

- 表 `qa_question(package_id, user_id, content≤500, anonymous, status visible|hidden, pinned)`、`qa_answer(question_id, user_id, coach_id NULL, is_coach, content≤1000, status, pinned)`。
- 提问：登录即可（不限已购），可选匿名；先发后审（默认 visible，后台可隐藏）。
- 回复权限：该课包关联教练（coach_package，认证标识、排序优先）或已购学员（存在 paid/refunding/refunded 订单）。
- 接口：公开 `GET /api/v1/packages/:id/qa`（置顶优先、教练回复靠前）；学员 `POST /api/v1/qa/questions`、`GET /api/v1/qa/mine`、`POST /api/v1/qa/questions/:id/answers`；教练 `GET /api/v1/coach/qa` + 回复/置顶；后台 `GET /admin/api/v1/qa` + 隐藏/恢复/置顶（问题与回答两级）。
- 通知：新提问 → 课包全部教练（`qa_new`）；新回复 → 提问者（`qa_reply`）。
- 前端：课包详情「评价|问答」Tab + 提问弹窗；`pages/qa/mine`；coach-admin「留言答疑」；admin-web `views/Qa.vue`。

## 批次⑤ 合规收尾 + 低成本工程修复

- **个人资料编辑**：`PUT /api/v1/me {nickname, avatarUrl}`（nickname trim 1~64；avatarUrl 须 `/uploads/` 或 `upload.base_url` 前缀或空）；mine 页 `open-type="chooseAvatar"` + `type="nickname"`。
- **admin 手机号脱敏**：admin-web 列表脱敏（Members/Orders）；**教练端保留明文**（排课联系学员业务必需）。
- **操作审计日志**：表 `admin_audit_log(admin_id, username, action, target_type, target_id, detail, ip, created_at)`；`AuditService.Log` 同步插入失败仅记日志；挂钩：退款审批/拒绝、手动调整课时、券保存/停发/发放、课包保存、教练审核、评价审核、配置保存、代客预约/核销。`GET /admin/api/v1/audit-logs` RequireBoss；admin-web `views/AuditLogs.vue`（菜单仅 boss）。
- **ratelimit 内存增长**：滑窗 allow() 惰性清理过期片 + 周期全量扫描；AdminLockout 过期清扫。
- **AdjustSessions 幂等（E7）**：调整请求可带 `clientKey` → 流水幂等键 `adjust:client:{clientKey}`，撞键拒绝；admin-web 弹窗每次打开生成 uuid。
