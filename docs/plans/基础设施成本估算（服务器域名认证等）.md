# 基础设施成本估算（服务器/域名/认证等）

> 日期：2026-10-23
> 说明：价格为**区间参考**（以腾讯云/阿里云活动价为准，新用户优惠力度大）；本方案延续已确认的「最简自建」路线：视频存自有服务器，不用对象存储/VOD。

## 1. 前置条件（一次性）

| 项目 | 费用 | 说明 |
|---|---|---|
| 营业执照 | ¥0 ~ ¥500 | 个体工商户可自己免费办（当地政务网）；代办约 ¥300-500。小程序企业认证和微信支付都需要主体资质，**必须先有** |
| ICP 备案 | ¥0 | 免费自行办理（腾讯云/阿里云有备案引导），周期约 1-2 周；域名 + 国内服务器必须备案才能对外提供 HTTPS 服务 |
| 小程序账号注册 | ¥0 | 注册免费，认证见下 |

## 2. 固定成本（每年）

| 项目 | 规格/说明 | 首年费用 | 续费（次年起） |
|---|---|---|---|
| 云服务器（腾讯云/阿里云轻量） | **2核4G、6-12M 带宽、含 1TB+ 流量包**，跑后端 + MySQL + nginx 视频静态服务 | ¥400 ~ ¥800（新用户活动价） | ¥1200 ~ ¥1800 |
| 域名 | .com（或 .cn 更便宜 ¥30-40/年） | ¥60 ~ ¥80 | ¥60 ~ ¥80 |
| SSL 证书 | 云厂商免费 DV 证书（每年可免费申领）或 Let's Encrypt 自动续期 | ¥0 | ¥0 |
| 微信小程序认证 | 企业/个体主体，微信支付的前提 | ¥300 | ¥300 |
| **固定合计** | | **约 ¥760 ~ ¥1180** | **约 ¥1560 ~ ¥2180（折合 ¥130-180/月）** |

省钱建议：

- 新用户首年优惠只能享受一次，部分厂商支持**新购 3 年锁价**（约 ¥1000-1500 拿下 3 年），比按年续费划算
- 服务器先买低配跑 P0，续费周期到了再按实际负载决定升配

## 3. 按量成本（随业务量）

| 项目 | 单价 | 估算 |
|---|---|---|
| 微信支付手续费 | 0.6% | 月流水 ¥3 万 → 约 ¥180/月；部分类目可申请 0.38% 优惠费率 |
| 手机号快速验证组件 | 约 ¥0.03/次 | 仅登录授权时调用；1000 个新用户约 ¥30 |
| 微信订阅消息 | ¥0 | 免费 |
| 短信（选配，可不买） | 约 ¥0.045/条 | 用订阅消息替代，P0 可完全不用短信 |

## 4. 视频自建存储的流量账（为什么 1TB 流量包够用）

- 课程介绍视频：1-2 分钟、720p、码率约 1.5Mbps → 单个约 20-30MB
- 1TB 流量 ≈ **3 万+ 次完整播放**
- 工作室几百名学员，介绍视频属低频观看（购前看 1-2 次），P0/P1 阶段流量包绰绰有余
- 注意：轻量服务器**带宽**（6-12M）限制的是并发——同一时刻只有约 3-6 人能流畅播放，对介绍视频场景可接受；若未来出现"多人同时跟练线上视频"的场景，再重新评估（上 CDN 或升带宽）

## 5. 明确不采购的项目（已决策）

| 项目 | 不用的原因 |
|---|---|
| 对象存储（COS/OSS） | 已决策视频自建服务器存储，降低成本与复杂度 |
| 云点播 VOD | 同上；课程介绍类短视频 nginx 直接提供播放地址 |
| 云数据库 RDS | 小规模自建 MySQL 单机够用，单买 RDS 约 ¥1000+/年，不值得 |
| CDN | P0/P1 流量小，暂不需要；流量接近 1TB/月时再评估 |

## 6. 总账

| 场景 | 估算 |
|---|---|
| **首年一次性投入** | 执照 ¥0-500 + 固定成本 ¥760-1180 ≈ **¥800 ~ ¥1700** |
| **稳定期年成本** | **约 ¥1600 ~ ¥2200/年**（不含支付手续费） |
| **月流水 ¥3 万时的支付手续费** | 约 ¥180/月 |

结论：基础设施层面每月成本约 **¥150-200**，主要开销是服务器续费；真正的成本大头在开发投入，不在基础设施。
