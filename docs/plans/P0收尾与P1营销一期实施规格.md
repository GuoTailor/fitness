# P0 收尾 + P1 营销一期 · 实施规格

> 日期：2026-10-25 · 依据：产品功能规划 §3.6/§3.8/§7.1/§7.2/§8 与差距盘点结论
> 批次：① 上传基础设施+评价图片 → ② 隐私/用户协议+客服 → ③ 优惠券底座+phone 唯一索引 → ④ 新人价+新人礼包
> 迁移：`00006_p1_coupon_newcomer.sql`（券两张表 / orders.newcomer_used / app_config.cfg_value 扩 TEXT / user.phone 唯一索引 / 新配置种子）

## 批次① 上传基础设施 + 评价图片

- **配置** `upload:` dir（默认 `data/uploads`）/ base_url（默认 `http://localhost:8080/uploads`）/ max_mb（默认 2）。
- **服务** `UploadService.SaveImage`：单图 ≤max_mb；白名单 jpg/png/webp 且**魔数校验**（防改扩展名）；路径 `images/{YYYYMM}/{32位随机hex}.{ext}`；返回 `base_url + 相对路径`。目录 MkdirAll。
- **路由** `POST /api/v1/uploads`（RequireUser，multipart 字段 `file`，wx.uploadFile 直接可用）；全局 body 上限 2MB→10MB（单图大小由服务层限制）。开发模式 gin `r.Static("/uploads", dir)`；nginx 增加 `/uploads/` location。
- **评价图片**：`POST /reviews` 增 `images: []string`（≤4 张，每张必须以 `/uploads/` 或 `upload.base_url` 开头——防外链注入）；`Review.Images` 存 JSON 数组字符串（现状）；列表接口输出解析后的 `images` 数组。小程序评价页 chooseMedia→逐张上传→预览/删除→提交；后台评价列表与教练回复弹窗展示图片。

## 批次② 隐私/用户协议 + 客服

- **配置键** `misc.privacy_content` / `misc.agreement_content`（后台可编辑，进 SaveConfig 白名单）；`app_config.cfg_value` 扩为 TEXT（协议文本超 512 字）。
- **公开接口** `GET /api/v1/agreement?type=privacy|user`（无 JWT，返回 {title,content}；空配置返回占位提示）。
- **小程序** `pages/agreement/agreement?type=` 文本页；「我的」页加：隐私政策、用户协议菜单 + **客服按钮**（`open-type="contact"`）。

## 批次③ 优惠券底座 + phone 唯一索引

- **表**：
  - `coupon_template`：name / type(reduce 满减|discount 折扣) / threshold(满 X 分，0 无门槛) / amount(reduce=减免分；discount=万分比 8800=88折，限 1000~9900) / package_id(0=全场) / total_count(0 不限) / issued_count / per_user_limit(默认 1) / valid_days(领取后 N 天过期，默认 30) / status。
  - `user_coupon`：user_id / template_id / status(usable|used|expired) / order_id / expire_at / used_at；索引 (user_id,status)、template_id。
- **领取（领券中心）**：事务内先对模板行 `issued_count=issued_count+1 WHERE status=1 AND (total=0 OR issued<total)`（条件更新=行锁+总量防超发），再查本人已领数 <per_user_limit，超限回滚；插入实例 expire_at=now+valid_days。后台定向发放 = 同链路但不查 per_user_limit（仍受总量约束）。
- **可用券** `GET /coupons/usable?skuId=`：本人 usable 且未过期、门槛≤SKU 价、范围匹配（0 或该课包）；返回 benefit（优惠分）与 finalPay。
- **下单** `orders.Create` 第 4 参启用：事务内「建订单+建支付单+**条件 UPDATE 券 usable→used（绑定 order_id，expire_at>now）**」，0 行即回滚报「优惠券不可用」；amount=SKU价−benefit，**benefit 封顶 price−1 分**（微信支付要求实付>0）；orders.coupon_id=券实例 id、coupon_amount=benefit。**与新人价不叠加取低价**（见批次④）。
- **退款返还**：`finalizeRefund` 事务内，若 order.coupon_id≠0：`status = CASE WHEN expire_at>now THEN 'usable' ELSE 'expired' END WHERE id=? AND order_id=? AND status='used'`——退款成功券自动返还（过期不返）。拒绝退款不动券。
- **退款金额护栏（已有基础上自然成立）**：全额退=order.amount（券后实付）；折算退封顶 `order.amount−refund_amount`；折算单价仍按 SKU 原价快照（§3.9「按单次原价折算」）。
- **券过期任务**：RunOnce 增补 `usable 且 expire_at<=now → expired`。
- **phone 唯一索引**：迁移 `ALTER TABLE user ADD UNIQUE INDEX uk_user_phone(phone)`（先在开发库查重、清重复）；`BindPhone` 增查重「该手机号已被其他账号绑定」+ 捕获唯一键冲突兜底。**新人价限购的数据前提**。
- **API（学员）**：`GET /coupons/center`（可领模板+已领次数+claimable）、`POST /coupons/:id/claim`、`GET /coupons/mine?status=`、`GET /coupons/usable?skuId=`。
- **API（后台）**：`GET /admin/api/v1/coupons`（含领取/使用统计=对账）、`POST /admin/api/v1/coupons`（建，RequireBoss）、`POST /admin/api/v1/coupons/:id`（改 status/总量等，RequireBoss）、`POST /admin/api/v1/coupons/:id/grant {userId}`（定向发，RequireBoss）。
- **前端**：小程序 `pages/coupon/center`、`pages/coupon/mine`；课包详情购买面板增「优惠券」选择（不使用/各券+折后价）；订单列表券后价标签。admin 新增「优惠券」页（列表/新建/停用/定向发/核销对账），订单抽屉展示优惠金额。
- **不做（记遗留）**：赠课券（非价格扣减，需入账钩子）、退款返还的二次有效期顺延、评价/打卡奖励发券、与限时活动价叠加规则。

## 批次④ 新人价 + 新人礼包

- **判定**（服务端 `orders.Create` 内）：`sku.newcomer_price>0` && 用户已绑手机号 && 不存在 `orders.newcomer_used=1 且 status<>closed` 的同手机号订单（JOIN user 按 phone 判重）。
- **取价**：新人可享时 `discount_newcomer = price − newcomer_price`；若同时传券：分别算 benefit，**只应用优惠更大者**（不叠加，规划 §7.1「与营销价默认不叠加、取最低价」）——用新人价则券不核销保持 usable，用券则 newcomer_used=0。amount≥1 分。
- **展示**：课包详情接口按当前登录用户返回每个 SKU 的 `newcomerEligible`；小程序详情页「新人价」角标+划线价；列表页有新人价即打标（ eligibility 下单时服务端终判）。后台 SKU 编辑器增新人价输入（0=关闭，须 < 原价）。
- **新人礼包**：配置 `marketing.newcomer_gift_templates`（CSV 模板 id）；`UserLogin` 新建用户成功后自动定向发放（复用 Grant 链路，失败只记日志不影响登录）。
- **不做（记遗留）**：体验课「预约第一节」强引导（现有购买后引导已够）。
