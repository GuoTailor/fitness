## 批次① 老带新裂变（00012_referral.sql）

- `referral_record(id, inviter_id, invitee_id UNIQUE, status 1=bound/2=rewarded, created_at, rewarded_at, KEY(inviter_id))`
- 种子 `marketing.referral_inviter_template` / `marketing.referral_invitee_template`（空=奖励关闭）
- Bind：自邀/已绑定（uk 兜底）/老客（存在 paid|refunding|refunded 订单）拒绝；成功插 bound
- RewardOnPaidOrder：HandlePaySuccess 入账后（事务外）调用；bound 且 ≤30 天 →
  条件 UPDATE 1→2 幂等闸门 → 双方 `Grant` 模板券（绕过每人限领），失败仅日志
- 路由 `POST /api/v1/referral/bind`、`GET /api/v1/referral/mine`、`GET /admin/api/v1/referrals`
- 小程序：index/course detail `onShareAppMessage` 带 `?inviter=<uid>`；index onLoad 解析+登录后 bind；
  mine 页邀请卡（open-type=share）；admin-web `Referrals.vue`

## 批次② 打卡挑战（00013_checkin.sql）

- `checkin_reward(user_id, period VARCHAR(7), UNIQUE uk_ck(user,period))`
- 种子 `marketing.checkin_target`（空=关闭）、`marketing.checkin_reward_template`
- Status：training_record 本月 COUNT(*) vs target；Claim：达标 + uk 撞=本月已领 →
  `Grant`（同一模板月度重复领会被 per_user_limit 挡，必须 Grant）
- 路由 `GET /api/v1/checkin/challenge`、`POST /api/v1/checkin/claim`；training 页挑战卡

## 批次③ 拼团（00014_groupbuy.sql）

- `package_sku` += group_price(0=未开) / group_capacity(2~5)；`orders` += group_buy_id
- `group_buy(sku_id, package_id, capacity, price, status 1=enrolling/2=success/3=failed, leader_user_id, expire_at, success_at)`
- `group_buy_member(group_buy_id, user_id, order_id, UNIQUE uk_gbm(group,user))`
- 种子 `marketing.group_expire_hours`（默认 48）
- Open/Join：拼团价建单（**不叠加券/新人价/活动价**，独立建单不复用三方比价）+ member 行（uk 防重复）→ prepay
- 支付成功正常 creditSessions（先入账，未成团靠退款回收）→ TrySucceed：已支付数≥capacity →
  条件 UPDATE enrolling→success → 通知全员（场景 groupbuy_success）
- Runner.CloseGroupBuys：过期且 enrolling → 条件 UPDATE→failed → 每已支付订单自动退款
  （建 Refund → 复用 ApproveRefund 链路，adminID=0 + 审计 groupbuy.autorefund）→ 通知 groupbuy_fail
- 路由 `POST /api/v1/group-buys`、`POST /:id/join`、`GET ?skuId=`、`GET /mine`、admin 列表
- 前端：detail 拼团价区块、groupbuy/list+detail 页（分享带 gbid+inviter）、order 拼团标签、
  Packages.vue 拼团控件、admin-web GroupBuys.vue

## 批次④ 教练入驻（00015_coach_application.sql）

- `coach_application(owner_id, user_id, name, gender, years, specialties, cert_images TEXT, intro, phone, status 0=pending/1=approved/2=rejected, reject_reason, admin_id, created_at, updated_at)`
- Submit：已是教练/已有 pending 拒绝；cert_images 1~6 张站内 `/uploads/` 前缀
- Review(approve)：pending→approved 条件更新 → 事务内 upsert coach（user_id 查有无，status=1、cert_verified=1）
  → 审计 → 事务外通知 coach_apply_result；reject 留痕+通知；admin 端 RequireBoss
- 修复：coach UpdateProfile 改 cert_images → 重置 cert_verified=0
- 前端：`pages/coach/apply`（表单+资质图上传+状态展示），入口 coach/list 底部 + mine 页；
  admin-web CoachApplications.vue（资质图预览）
